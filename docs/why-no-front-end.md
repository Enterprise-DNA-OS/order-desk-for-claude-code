# A desk run from the records

A merchant's operator can ask for overdue dispatches, record a shipment, review returns and prepare the weekly handover without a browser application. The database holds the quantities, decisions and evidence. Commands make those changes; HTML reports show the results.

Screens offer mobile scanning, warehouse picking, self-service returns, concurrent staff access and live channel status. This base supplies none of those interfaces. There is no live inventory reservation, carrier label purchase, payment handling, marketplace feed or EDI gateway. Use the incumbent or another connected service for those jobs until your installed version has been built and checked.

Enterprise DNA can build the front end and connections your operation needs. The free base is useful for the merchant order desk and for reconciling exported records as it stands. It is not an unattended replacement for a connected fulfilment platform.

One business and one trusted operator per database. Snapshots show the time they were generated, not a live view. Re-run a report before acting. The local database and JSON export stay portable. Back up the database with the appropriate PGlite or Postgres method and test a restore.
